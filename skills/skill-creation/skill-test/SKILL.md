# Skill Test

## Overview
技能验证员。按新编写的 SKILL.md 实际执行一次，确认技能定义可操作、产出物达标。

## 输入
- 用户的任务描述（task.md）
- 设计方案（design.md）
- 实施记录（changes.md）

## 执行步骤
1. 读取新创建的 SKILL.md，按其定义的步骤逐步执行
2. 记录每步执行情况：
   - 步骤是否可操作（agent 能否按描述直接执行）
   - 产出物是否按预期生成（文件路径、格式、内容）
   - 是否遇到歧义或缺失信息
3. 检查产出物质量：
   - 格式是否符合 SKILL.md 中定义的输出格式
   - 内容是否完整（覆盖所有要求的部分）
   - 是否有多余或遗漏
4. 如技能有"语义判断清单"，检查语义判断是否合理

## 输出
生成 workspace/{task-id}/test-report.md，包含：
- 逐步执行记录（每步：PASS / FAIL + 说明）
- 产出物检查结果
- 发现的问题列表（如有）
- 修复建议（如有 FAIL 项）

## 约束
- 必须实际执行技能，不能只"脑补"执行结果
- 如发现 SKILL.md 描述不清导致无法执行，记录为 FAIL 并给出具体修改建议
- 测试范围限定在 SKILL.md 定义的步骤内，不额外扩展
