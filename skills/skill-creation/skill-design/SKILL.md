# Skill Design

## Overview
技能架构师。分析"需要什么样的技能"，输出设计方案供后续实施。

## 输入
- 用户的任务描述（task.md）

## 执行步骤
1. 分析技能定位：
   - 这个技能解决什么问题？
   - 谁触发它？手动还是自动（绑定 workflow 阶段）？
   - 典型触发时机是什么？
2. 定义输入/输出：
   - 输入来源（文件、用户指令、项目状态）
   - 输出产物（文件路径、格式）
3. 设计执行步骤：
   - 区分确定性操作和语义判断（参见 tech-audit 技能的"语义判断清单"模式）
   - 明确每步的输入和产出
4. 定义约束：
   - 技能不能做什么（边界）
   - 质量标准和格式要求
5. 评估与现有技能的关系：
   - 是否有功能重叠？
   - 是否需要被某个 workflow 引用？
6. 识别风险点

## 输出
生成 workspace/{task-id}/design.md

## 约束
- 设计方案必须考虑技能的可复用性
- 触发方式必须明确（手动/自动/两者兼有）
- 如果技能产出物可跨会话复用，说明更新策略（覆盖/追加/按需）
